# WorkSafePro

App de Segurança do Trabalho para uso em obra.

## Como abrir no AndroidIDE

1. Abra o AndroidIDE no celular.
2. Escolha **Clone Repository**.
3. Cole o link:

```txt
https://github.com/Natividade0/WorkSafePro.git
```

4. Abra o arquivo `index.html`.

## Situação atual

O repositório já está conectado e recebeu o arquivo inicial `index.html`.

A versão web funciona como app HTML/CSS/JavaScript e pode evoluir para APK Android usando WebView.

## Observação importante

Os dados do app web ficam salvos no navegador usando `localStorage`. Faça backup JSON periodicamente quando essa função estiver disponível no app completo.
